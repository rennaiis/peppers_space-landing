### чтобы развернуть сайт локально: 

Для работы должeн быть установлен [node.js](https://nodejs.org/en/)

В папке с исходниками надо установить зависимости, выполнив:

```bash
npm install
```

для запуска локально нужно выполнить:
```bash
npm run dev
```

## Сборка

Сборка в папку out/:

```bash
npm run build
```
